# Alex Morgan — Developer Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript. No build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Personalize before publishing

The current content is illustrative. Update the name, bio, location, metrics, skills, project descriptions, project links, email, GitHub and LinkedIn URLs in `index.html` and `script.js`. Replace the sample project artwork as needed. Add your own `resume.pdf` beside `index.html` so the Resume link works. Update the page title and description in the document head.

## Deploy

This folder can be deployed as a static site to GitHub Pages, Netlify, or Vercel. For GitHub Pages, push the contents of this folder to a public repository and enable Pages for the default branch. For Netlify or Vercel, import the repository and use the project root as the publish directory; no build command is needed.

## Included interactions

- Responsive mobile navigation with accessible expanded state
- Dark and light themes, saved in local storage
- Smooth in-page navigation
- Project detail dialogs with stack and links
- Reduced-motion support
