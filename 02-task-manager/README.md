# Daymark

A calm, responsive task manager built with HTML, CSS, and vanilla JavaScript. It has no build step, framework, or server dependency.

## Use

Open `index.html` in a modern browser. Tasks and theme preference are saved in browser localStorage and remain on that device/browser.

## Features

- Create, edit, complete, and delete tasks
- Work, Personal, and Study categories
- Optional due dates with overdue indicators
- All, Active, and Completed status filters
- Category filters and quick search
- Drag-and-drop task ordering
- Completion progress and clear-completed action
- Light and dark themes
- Responsive layout and reduced-motion support

Tasks use the `daymark.tasks.v1` localStorage key. No server or account is involved.
